# Curated matrix-study evidence

This directory shares the audited summary CSVs, configuration/data checks and compact verification receipts from the 65-task Colab study. The original logs, optimizer states, full per-run checkpoints and bulk predictions remain in the local experiment collection and are excluded from this collaboration repository.

The published reports describe the original completed research. These copied records retain their numerical values and historical scope; copying them is not a new experiment or independent confirmation. File paths inside original records may refer to that original environment. The [layout map](../../../docs/project_layout_migration.json) resolves shared evidence and figure locations.
