# Historical fold-five baseline comparison

This directory retains the earlier 400-clip fold-five comparison. In `comparison.json`, **left** denotes CNN–BiGRU and **right** denotes CNN: their fixed-checkpoint accuracies are 62.00% and 61.50%, respectively.

The paired difference is 0.50 percentage points, with a conditional source-bootstrap interval of approximately −3.90 to +4.89 points. The comparison contains 310 recording sources and uses 2,000 source-group resamples.

These earlier fold-five scores are distinct from the main 398-clip development comparison. All official folds have historical exposure; the retained results are not an untouched final-test confirmation.
