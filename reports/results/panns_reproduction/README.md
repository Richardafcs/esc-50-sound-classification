# PANNs feature-extraction reproduction

A second Colab execution repeats frozen PANNs feature extraction and the linear-classifier fit used in the main comparison. It again produces **363/398 correct predictions, 91.21% accuracy and 91.10% macro-F1**, with the head converging in 137 iterations.

This is a computational reproduction using the same recordings, representation and fitting procedure. It is not an independent dataset evaluation or an additional randomly initialized encoder fit.
