# Figures

[index.json](index.json) lists the 40 research figures displayed in the [main results notebook](../../notebooks/01_results.ipynb), with captions, scope and source paths.

Shared model-comparison and historical figures are stored here. Supplementary figures remain beside their experiment tables in [reports/results/](../results/README.md). PNG files provide portable previews; SVG versions are included where available.

Re-executing the supplementary notebooks writes regenerated figures to the ignored `results/figures/` directory. The committed figures retain the completed experiment presentation.
